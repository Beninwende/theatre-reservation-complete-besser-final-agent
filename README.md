Agent and diagrams were created with the [BESSER Web Modeling Editor](https://editor.besser-pearl.org).  
**Business logic, REST API, and web UI** were added manually for the full course deliverable — see **[ATTRIBUTION.md](ATTRIBUTION.md)**.

Patrons book seats through conversation: capacity checks, `NOT_ENOUGH_SEATS`, profile-aware FAQ (`STANDARD` / `ACCESS`).

## Project structure

```
Theatre_reservation_agent.py   BESSER entry point → theatre_bot.py
theatre_bot.py                 Full BAF agent (manual implementation)
config.yaml                    Runtime config (BESSER template + local edits)
render.yaml / render-agent.yaml Render blueprints
buml/                          WME model export (diagrams.json)
wme-theatre-reservation-bot.json   Re-import into WME
backend/                       FastAPI (manual, Lab 6)
webapp/                        Static dashboard (manual, Lab 6)
```

## Quick start

```bash
pip install -r requirements.txt
python scripts/build_wme_export.py
python scripts/export_buml.py
python tests/smoke_test.py
```

### Chatbot

```bash
export OPENAI_API_KEY='sk-...'
python Theatre_reservation_agent.py
```

Demo: `STANDARD` → `BOOK` → `Hamlet` → `2` → `FRONT` → `NAME: Ada Lovelace` → `NONE`.

### API + web

```bash
export THEATRE_PERSIST=1
uvicorn backend.main_api:app --reload --port 8000
```

Open `webapp/index.html`.

### Docker

```bash
export OPENAI_API_KEY='sk-...'
docker compose up --build
```

| Service | URL |
|---------|-----|
| API | http://localhost:8000/docs |
| Web | http://localhost:3000 |
| Agent | http://localhost:5000 |

## WME

Import `wme-theatre-reservation-bot.json` in the editor. Regenerate: `python scripts/build_wme_export.py`.
