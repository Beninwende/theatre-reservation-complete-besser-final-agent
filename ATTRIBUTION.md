# Attribution — BESSER vs implementation manuelle

Projet initial créé via le [BESSER Web Modeling Editor](https://editor.besser-pearl.org) (export agent → GitHub).  
Cette version complète le livrable cours BESSER (labs 1–7) avec du code métier et une stack web ajoutés **à la main**.

## Généré ou assisté par BESSER (WME / export éditeur)

| Élément | Source |
|---------|--------|
| Structure du repo agent (`Theatre_reservation_agent.py`, `config.yaml`, `render.yaml`, dossier `buml/`) | Export GitHub depuis l’éditeur BESSER |
| Diagrammes (class, agent, user, GUI, object) | Modélisés dans le WME ; export `wme-theatre-reservation-bot.json` |
| `buml/diagrams.json` | Dérivé du projet WME (`scripts/export_buml.py`) |
| Squelette agent **initial** (états = textes fixes, classifieur simple) | Générateur agent BESSER — **remplacé** par `theatre_bot.py` (voir ci-dessous) |
| Badges README « Generated by BESSER » | Template export éditeur (conservés) |

## Implémenté à la main (hors générateur agent)

| Fichier / partie | Rôle |
|------------------|------|

| `Theatre_reservation_agent.py` | Point d’entrée BESSER → délègue à `theatre_bot.py` |
| `reservation_store.py` | Catalogue, capacité, SQLite (`THEATRE_PERSIST`) |
| `data/shows.yaml`, `data/user_profiles.yaml` | Données et profils Lab 7 |
| `backend/main_api.py` | API REST FastAPI (Lab 6) |
| `webapp/index.html` | Interface web légère (Lab 6) |
| `models/domain_model.py` | Modèle B-UML (Lab 1) |
| `generate_programme.py`, `templates/programme.md.j2` | Générateur Jinja (Lab 3) |
| `scripts/build_wme_export.py` | Construction / enrichissement du JSON WME (diagramme agent complet) |
| `scripts/export_buml.py` | Export `buml/` |
| `tests/smoke_test.py` | Tests hors ligne |
| `docker-compose.yml`, `Dockerfile`, `render-agent.yaml`, `render.yaml` (API) | Déploiement |
| `docs/STATE_MAP.md`, `docs/LIVRABLE.md` | Documentation cours |

## Comment présenter le projet

- **Modèles** : créés / maintenus dans le WME (fichier JSON importable).
- **Comportement du bot** : `theatre_bot.py` (manuel, aligné sur les modèles).
- **Application web** : `backend/` + `webapp/` (manuel, complément Lab 6).
